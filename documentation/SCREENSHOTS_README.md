# Required project evidence screenshots

These screenshots must be captured from the intern's own running application. They are intentionally not fabricated or pre-filled.

Save PNG/JPG images in this folder with these filenames:

1. `01_health_api.png` — Swagger `GET /` endpoint executed successfully; expected JSON includes `status: ok` and `project: PY-W4-004`.
2. `02_register_or_login.png` — successful registration or login response. Hide/remove tokens and never expose passwords.
3. `03_employee_api.png` — employee endpoint response (use sample/test data only).
4. `04_document_upload.png` — successful upload response showing file metadata; do not include confidential documents.
5. `05_workflow_decision.png` — workflow approval/rejection response and, if possible, history.
6. `06_reports.png` — report endpoint response or downloaded report file.
7. `07_dashboard.png` — running Streamlit dashboard.
8. `08_tests.png` — terminal showing `pytest -q` result.

In Windows, use `Win + Shift + S`, select the relevant area, save the screenshot in this folder, and use the exact filename above. Do not include real employee personal data, passwords, JWT tokens, or confidential company documents.
